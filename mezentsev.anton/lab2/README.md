# Лабораторная работа 2

## Задание

Вариант 28. Написать функцию `calculateExpression(expr)`, вычисляющую значение
математического выражения в строке. Например, для `"2 + 3 * 4"` результат равен `14`.

## Реализация

Файл `solution.js` является ES-модулем и содержит именованный экспорт
`calculateExpression`. Функция синхронно возвращает число.

Выражение разбирается последовательно с помощью трёх функций:

- `parseExpression` обрабатывает сложение и вычитание;
- `parseTerm` обрабатывает умножение и деление;
- `parseFactor` читает число, знак перед числом или выражение в скобках.

Такой порядок обеспечивает приоритет умножения и деления над сложением и
вычитанием. Операции одинакового приоритета выполняются слева направо.
Пробельные символы между элементами выражения пропускаются.

Дополнительно поддерживаются отрицательные числа, скобки и дробные числа с точкой.
При неправильном типе аргумента, ошибке синтаксиса, делении на ноль или
непредставимом конечным числом результате выбрасывается исключение.
Вычисления используют стандартный тип `Number` JavaScript и его точность.
`eval` и `Function` не используются. При импорте файл ничего не выводит в консоль.

## Запуск

Используйте Node.js 24.19.0, указанный в README курса.
Разместите папку `lab2` в своём каталоге `surname.name` репозитория курса.
Замените `surname.name` своей фамилией и именем латиницей в нижнем регистре.
Отдельный `package.json` внутри `lab2` не нужен.

Перейдите в каталог лабораторной и выполните:

```bash
node --input-type=module -e "import { calculateExpression } from './solution.js'; console.log(calculateExpression('2 + 3 * 4'));"
```

Ожидаемый результат: `14`.

Примеры вызовов после импорта функции:

```js
calculateExpression('2 + 3 * 4'); // 14
calculateExpression('(2 + 3) * 4'); // 20
calculateExpression('10 - 8 / 2'); // 6
calculateExpression('-5 + 2 * 3'); // 1
calculateExpression('1.5 * 4 + 2'); // 8
```

Из корня репозитория курса запустите проверки:

```bash
npm run format -- surname.name/lab2
npm run format:check -- surname.name/lab2
npm run lint:js -- surname.name/lab2
```
